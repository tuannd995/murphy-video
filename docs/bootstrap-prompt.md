# Prompt khởi động (đã chuyển)

Bộ khởi động đầy đủ giờ nằm ở thư mục [`kit/`](../kit/). Kit tự đủ, không cần clone repo này:
1. Copy nguyên thư mục `kit/` vào một thư mục trống trên máy.
2. Mở Claude Code ở thư mục đó.
3. Dán prompt trong [`kit/00-START-HERE.md`](../kit/00-START-HERE.md).

Kit dùng chung cho mọi kênh và mọi video.
